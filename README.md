# Travel Cost Calculator

Plan domestic (Bangladesh) and international trip budgets with destination-based
cost estimates.

## Features

- **Domestic + international modes** — 9 Bangladesh destinations, 14 international
- **Destination-based suggested costs** — researched mid-range averages for hotel,
  food, local transport, activities, visa fees and round-trip flights from Dhaka
  (every value editable)
- **Travel styles** — Budget / Mid-range / Luxury multipliers
- **Custom expense categories** — add your own cost lines (per person or group)
- **Group split** — per-person totals from group size
- **Currency** — BDT + USD with live USD→BDT rate (editable, offline fallback)
- **Saved trips** — kept in the browser (local storage)
- **PDF export** — print-optimized report
- **Live price links** — Google Flights & Booking.com for the chosen destination

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deployed on Vercel.
